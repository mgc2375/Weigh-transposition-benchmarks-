# Weigh-transposition-benchmarks-
Benchmark test for weight transposition - distillation of skills via direct weight editing executed via transposition. Testing transposition of GLM 5.3 skills into qwen 2.5 coder

Qwen2.5 Transposed scores 11.6 points lower than GLM-5.3 on AA Coding Index (−15.5%), 19.9 points lower on SWE-bench (−29.7%), 23.5 points lower on FrontierSWE (−30.1%), 21.5 points lower on SWE-Marathon (−50.6%), and 9.73 points lower on SciCode (−16.5%). It scores 7.6 points higher on Terminal-Bench v3.0 (+26.9%). Compared with Qwen2.5-Coder 32B Instruct, Transposed scores 38 points higher on SWE-bench (+422.2%) and 33.4 points higher on LiveCodeBench (+106.4%).
